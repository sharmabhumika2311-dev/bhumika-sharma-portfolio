# Bhumika Sharma — Portfolio

A single-page animated portfolio built with plain HTML, CSS and JavaScript (no build step).

- Three.js particle hero (loaded from cdnjs)
- Scroll-reveal animations, count-up stats and a scroll progress bar
- Placeholder images from picsum.photos
- Palette: `#7C5CFF` `#22D3EE` `#F472B6` on `#0B1020`

Open `index.html` in a browser, or deploy the repo root as a static site.
